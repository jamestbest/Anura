formal information
 mapping of function and local variables to points in the data
LINDEP: linear dependancy, my value is derived from the value at this point
SPLDEP: Split dependancy, my value is derived from one of the following points
CNDDEP: Conditional dependancy, the value of this dependancy may not execute (Condition then value)
ENDDEP: Sentinal value for end of chain
EXPR(sym, type): This is an expression in code of sym (e.g. +,==,!=) of type in TYPES
TYPES: {LEFT, RIGHT, BOTH_R}, the type of expression if left then it only depends on the
  left value and should be derived by context, same for right
  if both then it can only stop on the right expression and should save the left's stack frame
